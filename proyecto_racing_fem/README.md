# Proyecto Web Oficial Racing Fem

Página web completa, interactiva y responsive para el equipo de fútbol femenino **Racing Fem**, construida con HTML5, CSS3 y JavaScript Vanilla.

## 🎨 Estética y Diseño
- **Verde Oscuro (`#0B3B24`)**: Color principal del club.
- **Crema/Blanco Cálido (`#FDFBF7`)**: Fondos limpios y elegantes.
- **Dorado (`#C5A059`)**: Detalles, botones, bordes y destacados.
- **Adaptabilidad**: Diseño completamente responsive (escritorio, tablet y móvil).

## 📁 Estructura del Proyecto
- `index.html`: Pantalla de bienvenida con selección de perfil y animación de carga.
- `inicio.html`: Portada principal con carrusel panorámico y carrusel horizontal interactivo de partidos.
- `plantilla.html`: Plantilla oficial con las 22 jugadoras organizadas por demarcación (Porteras, Defensas, Centrocampistas, Delanteras).
- `partidos.html`: Calendario completo de 26 jornadas de liga más la eliminatoria de Copa de la Reina.
- `resultados.html`: Consulta de partidos ya disputados con marcadores y condición.
- `clasificacion.html`: Tabla interactiva con los 14 equipos de la Liga 2ª Federación (Grupo 1) y resaltado para Racing Fem.
- `noticias.html`: Portal de novedades e información del club.
- `encuestas.html`: Módulo de encuestas públicas interactivas para afición.
- `admin/login.html`: Inicio de sesión protegido para administradores.
- `admin/dashboard.html`: Panel CRUD para gestionar plantilla, marcadores, noticias y encuestas.
- `css/estilos.css`: Hoja de estilos centralizada.
- `js/site-data.js`: Base de datos inicial y sincronización con `localStorage`.
- `js/public-pages.js`: Lógica de renderizado e interacción de las páginas públicas.
- `js/admin.js`: Lógica de administración y gestión del panel.
